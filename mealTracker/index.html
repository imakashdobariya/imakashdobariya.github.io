How it works: A single Google Apps Script Web App powers everything. It reads employees from your Employees sheet tab and writes daily attendance to your MealAttendance tab. Deploy it once, paste the URL below — done.

📋 Setup Guide — Google Apps Script

  1. Open (or create) a Google Sheet
  2. Create two tabs: Employees and MealAttendance
  3. In the Employees tab, row 1 must have these headers: ID  |  Name  |  Department
  4. Fill in your employee rows starting from row 2
  5. Go to Extensions → Apps Script, replace all existing code with the script below
  6. Click Deploy → New Deployment → Web App
  7. Set Execute as: Me  and  Who has access: Anyone
  8. Copy the deployment URL → paste it above → click Save & Connect
